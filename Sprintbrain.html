Syntax reference
{{YOUR_PRICE}}

Input placeholder. Shown as a form field.

{{= YOUR_PRICE * 0.985 }}

Evaluated math formula. Result shown inline (2 dp).

{{= round(OTA_PRICE * 0.015) }}

Built-in functions: round, floor, ceil, abs, min, max.

{formtext: name=VAR; default=x}

Text input with optional default value.

{formdate: name=VAR}

Date picker input.

{formmenu: A,B,C; name=VAR}

Dropdown menu — comma-separated options.

{button label="10% off"}PRICE = PRICE * 0.9{/button}

Action button. Sets field values when clicked; never appears in the message. Add trim=left so it leaves no blank line.

{time: DD/MM/YYYY HH:mm}

Current date/time formatted inline.

{if: VAR = "value"}…{endif}

Conditional block. Supports = == != comparisons.

{if: …}…{elseif: …}…{else}…{endif}

Multi-branch conditional. First matching branch is shown.

{var: TOTAL = PRICE * NIGHTS}

Local variable computed from other fields.

Querido {NOMBRE}

Greetings agree with the name: Lucía gets "Querida", Marco gets "Querido". Works for Querido, Estimado, Bienvenido, Caro, Cher and their pairs. Unknown names keep the word you wrote.

{gender: NOMBRE; m=invitado; f=invitada; u=invitado/a}

Any other gendered word. u is the fallback for unisex names like Alex.
