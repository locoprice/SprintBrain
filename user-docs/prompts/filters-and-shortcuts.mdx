## Filter the library

On the Prompts page, the bar above the cards narrows the list:

- **Folders**: click **All prompts** or a folder. Prompts use the same folders as snippets.
- **Strategy** and **Intent**: pick a value to show only matching prompts.
- **Labels**: the same labels as snippets. **Manage labels** opens the list to edit them.

The search bar at the top of the dashboard looks through prompts, snippets and memory together.

## Prompt cards

- Click a card to edit the prompt.
- Hover over **Details** or focus it with the keyboard to read all assigned labels. Click to keep it open; press **Esc**, click outside, or use **Close details** to dismiss it. Labels remain searchable while hidden.
- **Use** opens the full prompt with a **Copy** button. If Interactive Steps is on, the copy includes the step-by-step instructions.
- Pin a prompt to keep it at the top of the list. The **⋯** menu has **Pin to top** and **Delete**.
- Prompts nobody has used for six months get the same notice as snippets, with **Delete**, **Modify** and **Keep**.

## Insert in any text field

- Type `"""` to open the **Prompt mode** menu. Use <kbd>↑</kbd> and <kbd>↓</kbd>, then <kbd>Tab</kbd> or <kbd>Enter</kbd> to insert.
- Type `"""` followed by a prompt's shortcut, like `"""followup`, to insert it straight away.

To set a shortcut, open the prompt and fill in **Shortcut**. Use letters, numbers, `-` and `_`.
