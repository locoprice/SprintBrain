## Install

<Steps>
  <Step title="Add it to Chrome">
    Open [SprintBrain on the Chrome Web Store](https://chromewebstore.google.com/detail/khdpimdpkgmmaimpbfjgglnpaemmopoo), click **Add to Chrome**, then **Add extension**.
  </Step>
  <Step title="Pin it">
    Click the puzzle icon in the Chrome toolbar and the pin next to SprintBrain, so its icon stays in view.
  </Step>
  <Step title="Sign in">
    Click the SprintBrain icon and choose **Sign in via dashboard**. A tab opens on app.sprintbrain.com, links the extension to your account and closes by itself.

    Prefer a code? Choose **Use email code instead**, type your email and click **Send code**, then type the code from the email.
  </Step>
</Steps>

The extension needs Chrome on a computer, or another browser that installs extensions from the Chrome Web Store.

## What it adds

- **Snippets as you type**: type `::` and a trigger in any text field. See [Ways to insert](/text-snippets/insert).
- **Prompts as you type**: type `"""` for your prompt menu. See [Prompts](/prompts/overview).
- **A right-click menu**: **Insert SprintBrain snippet** in text fields, and **Save selection to SprintBrain** on selected text.
- **Suggestions for selected text**: select a word in a field to see matching snippets.
- **A Context button on AI chats**: add what your [Brains](/brains/overview) know to a message in ChatGPT, Claude and other assistants. The shortcut is <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>M</kbd> (<kbd>Cmd</kbd> <kbd>Shift</kbd> <kbd>M</kbd> on a Mac).

## The popup

Click the SprintBrain icon in the toolbar:

- Switch between **Snippets** and **Prompts**, search, and filter by folder.
- Click a snippet to open it, fill in its fields and click **Copy filled**.
- **Open Dashboard** takes you to app.sprintbrain.com.
- On a ChatGPT or Claude conversation, **Save this chat** keeps it in a Brain.

The gear opens the extension's own settings: **Suggest on selection**, **Automatic capitalization**, **Default Language** and **Sign out**. Snippets, folders and triggers are managed in the dashboard.

## Updates

Chrome updates the extension by itself. To get a new version straight away, open `chrome://extensions`, switch on **Developer mode** at the top right and click **Update**.
