The SprintBrain extension works in Google Chrome on a computer, and in other browsers that install extensions from the Chrome Web Store.

## Fields it works in

- Single-line boxes: text, search, email, web address and phone number fields.
- Larger text areas.
- Rich editors, the kind used by email, chat and AI tools, where you can format text.

No setup per site is needed.

## Where it can't run

Chrome doesn't let extensions into some pages: Chrome's own settings pages, the Chrome Web Store, and PDFs opened in the browser. It also can't reach apps outside the browser.

## When typing doesn't work

If a site blocks typed expansion, you have two ways around it:

- **Right-click menu**: right-click in the field and open **Insert SprintBrain snippet**.
- **The popup**: click the SprintBrain icon, open the snippet, fill it in and click **Copy filled**, then paste.

See [Ways to insert](/text-snippets/insert).

## On your phone

The extension doesn't run on phones. Open [app.sprintbrain.com/mobile](https://app.sprintbrain.com/mobile/) to search, fill and copy snippets, then paste them into any app. See [Mobile](/apps/mobile).
